# Карта квартир Петербурга

Интерактивная карта квартир из Google таблицы. Открывается по ссылке, вход в аккаунты не нужен.

- `index.html` — сама карта (собирается автоматически из таблицы).
- `tools/` — файлы для пересборки: шаблон страницы, скрипт и координаты домов.

На карту попадают только данные объявления: адрес, цена, площадь, этаж, метро, ремонт, парковка, ссылка.
Контакты продавцов и внутренние комментарии не выгружаются.

Чтобы обновить карту после новых строк в таблице, достаточно попросить Claude: «обнови карту».
